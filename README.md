# 🧬 강쌤의 과학 실험실

과목 → 대단원 → 소단원별로 📺 칠판 강의, ✏️ 손글씨 노트, 💻 웹앱을 모아 두는 수업 자료 사이트입니다.

## 파일 구성

| 파일·폴더 | 역할 | 수정 |
|---|---|---|
| `data.js` | 과목·단원 목차와 자료 목록 | ✅ 선생님은 이 파일만 고치면 됩니다 |
| `lectures/` | 칠판 강의 HTML | 파일 올리기 |
| `notes/` | 손글씨 노트 HTML·PDF | 파일 올리기 |
| `apps/` | 웹앱 HTML | 파일 올리기 |
| `index.html`, `app.js` | 화면 뼈대와 코드 | 고칠 필요 없음 |
| `style.css` | 디자인(색, 모양) | 색을 바꿀 때만 맨 위 부분 수정 |

## 자료 추가하기 (GitHub 웹에서)

1. 자료 파일을 해당 폴더(`lectures/`, `notes/`, `apps/`)에 **Add file → Upload files**로 올리기
2. `data.js` 열기 → 연필(✏️) 버튼 → 해당 소단원 칸에 한 줄 추가 → **Commit changes**
3. 1~2분 뒤 사이트에 반영

## 과목 관리

- `data.js`의 과목 덩어리 하나 = 왼쪽 탭 하나
- `name` 이름 변경, `group`("교과" / "탐구 주제") 묶음 변경, 순서 = 탭 순서
- 새 과목은 덩어리를 복사해서 붙이고 `id`만 다르게

## 페이지 주소

- 과목 첫 화면: `/#/bio`
- 소단원: `/#/bio/1/2` (생명과학 Ⅰ단원 2. 물질대사)
